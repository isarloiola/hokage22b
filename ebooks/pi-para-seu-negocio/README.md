# Pi para seu Negócio — O Guia Prático para Empreendedores e Comerciantes

Pasta editorial padronizada do guia comercial **Pi para seu Negócio**.

## Estrutura
- `assets/`: Recursos visuais e folhas de estilo.
- `build/`: Scripts de geração e empacotamento.
- `content/`: Textos-fonte em Markdown.
- `dist/`: Cópia mestra da capa oficial (`Capa_Pi_Para_Seu_Negocio.jpg`) e artefatos de distribuição.
- `plan/produto.json`: Ficha técnica comercial, preços (`3.14 π` / `R$ 19,90`) e links Hotmart (`A108356534I`).
